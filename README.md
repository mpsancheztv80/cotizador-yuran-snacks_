# 🥑 Cotizador YuraSnacks

Una mini web app responsiva de una sola página diseñada para calcular rápidamente cotizaciones de pedidos y costos de envío para WhatsApp.

## 🚀 Problema que resuelve
Elimina el cálculo manual de precios de packs y opciones de delivery, permitiendo responder a los clientes por WhatsApp en segundos y sin errores de cobro.

## 🛠️ Tecnologías utilizadas
* HTML5
* CSS3 (Diseño optimizado para celulares)
* JavaScript vanilla (Lógica de cálculo y copiado al portapapeles)

## 📦 Funcionalidades
* Selector de productos y packs preconfigurados.
* Cálculo automático de delivery o recojo en tienda.
* Generador de mensaje formateado listo para copiar y pegar en WhatsApp.

## 📱 Uso
1. Selecciona el producto y la cantidad.
2. Elige la opción de entrega (Recojo o Delivery).
3. Haz clic en **Calcular Total**.
4. Presiona **Copiar resumen para WhatsApp** y pégalo en el chat con tu cliente.
